# BFSI Customer & Loan Analytics Dashboard

## 1. Short Description / Purpose
Developed a BFSI analytics project using SQL to analyze customer profiles, banking behavior, account balances, credit scores, loan portfolios, repayment performance, and customer churn.
The project transforms customer-level financial data into actionable business insights through filtering, aggregation, segmentation, ranking, and business analysis queries. The analysis includes customer distribution by state, city, gender, employment type and customer segment, along with loan amount, outstanding loan, interest rate, delinquency, credit-card utilization, and churn analysis.

**Purpose:**
To help BFSI teams understand their customer base, identify financial risk indicators, evaluate loan performance, and support data-driven banking decisions.

## 2. 🛠️Tech Stack

MySQL and SQL were used to build and analyze the BFSI dataset through data querying, filtering, aggregation, grouping, sorting, conditional analysis, and business-oriented calculations. SQL functions such as `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `CASE`, etc were used to derive customer, account, loan, credit-risk, delinquency, and churn insights. **Power BI** can be used as the visualization layer to convert these analytical outputs into interactive dashboards with KPI cards, charts, tables, slicers, and drill-downs.

## 3. 🌟Features / Highlights
A. Customer Overview
Provides a high-level view of the customer base, including total customers, customer distribution by state and city, average customer age, average annual income, and average credit score.

Business Impact:
Helps management understand the overall customer profile and identify major geographic and demographic concentrations.
